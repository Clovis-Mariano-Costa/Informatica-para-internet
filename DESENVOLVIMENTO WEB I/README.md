## 📘 Sobre a unidade curricular

Este espaço reúne meus estudos, exercícios, atividades, códigos e anotações da unidade curricular **Desenvolvimento Web I — DWB014701**, do Instituto Federal de Santa Catarina — IFSC.

A disciplina introduz os principais fundamentos necessários para a construção de páginas e aplicações para a Web, avançando progressivamente de conceitos básicos da programação web até o uso de HTML5, CSS3 e JavaScript.

---

## 🎯 Conteúdos estudados

O cronograma da disciplina está organizado em quatro grandes etapas:

### 1. Fundamentos de Programação Web

📅 04/08/2026 a 17/08/2026

Introdução aos conceitos fundamentais relacionados ao funcionamento e desenvolvimento de aplicações para a Web.

---

### 2. Fundamentos da Linguagem HTML5

📅 18/08/2026 a 16/09/2026

Estudo da estrutura de documentos HTML e de elementos utilizados para organizar o conteúdo de páginas Web.

Entre os conteúdos praticados estão:

* estrutura básica de uma página HTML;
* elementos e tags;
* títulos e parágrafos;
* links;
* imagens;
* listas;
* tabelas;
* organização do conteúdo.

---

### 3. Fundamentos das Folhas de Estilo em Cascata — CSS3

📅 17/09/2026 a 16/10/2026

Introdução ao CSS e à separação entre estrutura e apresentação de uma página Web.

Nesta etapa serão estudados conceitos relacionados à:

* estilização de elementos HTML;
* cores;
* fontes;
* tamanhos;
* espaçamentos;
* bordas;
* posicionamento;
* organização visual;
* construção de layouts.

---

### 4. Introdução à Linguagem JavaScript

📅 17/10/2026 a 23/11/2026

Introdução da programação ao ambiente Web, permitindo acrescentar comportamento e interatividade às páginas.

Esta etapa representa a integração entre:

```text
HTML  → estrutura
CSS   → aparência
JavaScript → comportamento
```

## 🧱 HTML + CSS + JavaScript

Uma das ideias centrais do aprendizado é compreender o papel de cada tecnologia:

| Tecnologia     | Função                                 |
| -------------- | -------------------------------------- |
| **HTML5**      | Estrutura e conteúdo da página         |
| **CSS3**       | Aparência e apresentação visual        |
| **JavaScript** | Lógica, comportamento e interatividade |

Uma forma simples de visualizar:

```text
                PÁGINA WEB
                    │
        ┌───────────┼───────────┐
        │           │           │
      HTML         CSS      JavaScript
        │           │           │
   Estrutura    Aparência     Ações
```

## 📝 Avaliação

A avaliação da unidade curricular é composta por:

* **Mão na Massa 1 — MM1**
* **Mão na Massa 2 — MM2**
* **Prova 1 — P1**

A média final é calculada por:

```text
Média Final =
((MM1 + MM2) / 2 × 0,8)
+
(P1 × 0,2)
```

Portanto:

* atividades práticas representam **80% da média**;
* a prova representa **20% da média**.

A média mínima para aprovação na unidade curricular é **6,0**.
