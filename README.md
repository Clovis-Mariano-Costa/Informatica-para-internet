## 👨‍🎓 Sobre este repositório

Este repositório reúne meus estudos, exercícios, atividades, projetos e anotações desenvolvidos durante o curso **Técnico em Informática para Internet**, do **Instituto Federal de Santa Catarina — IFSC, Câmpus Florianópolis**.

O objetivo é acompanhar minha evolução ao longo do curso, organizar o conhecimento adquirido e construir um histórico prático do meu aprendizado em desenvolvimento de software e tecnologias para a Internet.

## 🎯 Objetivo do curso

O curso prepara profissionais para **analisar, projetar, desenvolver, implantar e manter sistemas e aplicações para a Internet**.

Durante a formação são trabalhados conhecimentos relacionados a:

* programação;
* lógica de programação;
* desenvolvimento web;
* banco de dados;
* análise e modelagem de sistemas;
* programação orientada a objetos;
* APIs e serviços web;
* desenvolvimento para dispositivos móveis;
* testes de software;
* segurança da informação;
* integração de sistemas;
* empreendedorismo;
* projetos integradores.

O curso do IFSC utiliza uma proposta de integração entre diferentes unidades curriculares por meio do desenvolvimento progressivo de um **protótipo de software**, permitindo aplicar na prática os conhecimentos adquiridos durante a formação.
