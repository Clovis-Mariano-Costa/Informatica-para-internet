## 📘 Sobre a unidade curricular

Este espaço reúne meus estudos, exercícios, atividades, anotações e trabalhos da unidade curricular **Banco de Dados I — BDD014701**, do Instituto Federal de Santa Catarina — IFSC.

A disciplina apresenta os fundamentos necessários para compreender como os dados são organizados, estruturados, armazenados e manipulados em sistemas computacionais.

---

## 🎯 Conteúdos principais

Entre os principais conteúdos previstos na disciplina estão:

- conceitos iniciais de banco de dados;
- modelo de dados relacional;
- organização e estruturação de dados;
- conversão de modelos;
- MySQL;
- SQL;
- criação e manipulação de bancos de dados.

---

## 🧩 Etapas de estudo

### 1. Modelo de Dados Relacional

📅 **13/10/2026**

O modelo relacional é uma das principais formas de organização de dados em bancos de dados.

Nesta etapa serão trabalhados conceitos relacionados a:

- tabelas;
- linhas;
- colunas;
- registros;
- atributos;
- relacionamentos;
- chaves.
